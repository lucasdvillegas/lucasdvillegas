## 👨‍💻 Sobre mí

Full Stack Developer con 3 años de experiencia especializado en el ecosistema JS/Vue y PHP/Laravel. Enfoque en el desarrollo frontend utilizando Blade, Vue 2/3, Nuxt y Quasar, con experiencia en la integración de estas tecnologías tanto en arquitecturas monolíticas con Inertia como en REST. 

Me especializo en:

- Desarrollo backend con **Laravel**
- Interfaces dinámicas con **Vue.js** y/o **Quasar Framework** **Composition API**
- Integración con **Inertia.js** para monolitos o **Axios** para **API RESTful**
- Desarrollo frontend con **TypeScript** y/o **Javascript**
- Diseño de APIs y arquitectura limpia
- Creación de componentes reutilizables
- Optimización y mantenimiento de aplicaciones web

Actualmente sigo mejorando mis habilidades en arquitectura de software, buenas prácticas y desarrollo de productos escalables.
